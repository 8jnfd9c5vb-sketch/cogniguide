# CogniGuide

CogniGuide is a study aid that uses artificial intelligence to transform users' uploaded digital notes into active learning materials. Its core feature is the automatic generation of quiz questions based on the notes, enabling users to self-test rather than simply re-reading the material.

## Teaching Guide (AI)

- Transfer learning
- Image to text
- Store user data to build a personal database

## Functions

- Generate questions and answers
- Provide daily quizzes in different subjects

## Highlights

- Support long-term study and revision
- Personalized learning experience
